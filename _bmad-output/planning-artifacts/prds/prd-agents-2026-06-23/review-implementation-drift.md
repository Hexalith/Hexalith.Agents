Classification key: **drift** = code contradicts a PRD rule; **gap** = a PRD rule with no code, reported only where the PRD or update report presents it as shipped or where it sits on a safety, audit, or readiness fail-closed path; **forbidden-shipped** = code still exhibits behaviour the PRD now forbids or deprecates.

## Verdict

The code has not moved since the baseline, so the four standing debt items are all still open, and the second PRD update widened the distance rather than narrowing it: it turned the §8 "disabled while not `Available`" description into FR-34 with a named blocker and attestation, added the Conversation Agent State machine, the FR-18 transition table, the FR-7 re-check, and the FR-34/FR-21 fail-closed outcomes, none of which has a symbol in the tree. Beyond the expected list, the review found that the shipped approval path enforces no segregation of duties at all (the approver is never compared with the caller or the last editor; `ApproverPolicyVerdict.Evaluate` takes only the policy and its source resolution), that neither the pre-Provider scan of prompt and Conversation Context nor the approval-time / pre-post re-check of the exact approved version exists (only generated output is scanned, and a human edit is never scanned anywhere), that `EnableProductionLikeGeneration` can succeed with no cost cap, rate limit, or payload-protection evidence, and that the Safe Context Budget is exactly the "subtracts only the output allowance" formula FR-9 now declares non-conformant. Membership is still established only at posting time, which FR-2 states "does not satisfy this requirement"; `PostingFailed` has no abandon exit and an unbounded retry through re-approval, which also re-enters an in-flight `PostingPending`; expiry is enforced only by the timer command, never on approve/edit/regenerate, and the default expiry reader records no expiry at all. Every one of these is masked today by the fail-closed `Deferred*` defaults in `Program.cs` — nothing content-bearing can run — but each is shipped logic that a host binding the live ports (`EXT-PROVIDER-1`, `EXT-CONV-AI-1`) would execute unchanged. Six findings are Critical, nine High, eight Medium, three Low. The one deferred baseline item, "narrowing A-1", gets the verdict: narrow it — `ParticipantType.AiAgent` is compiled against today.
