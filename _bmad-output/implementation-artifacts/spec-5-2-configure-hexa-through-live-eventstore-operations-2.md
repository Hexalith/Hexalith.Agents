## Intent

**Problem:** Story 5.2 must correlate every setup write with its exact EventStore outcome, but the current plan installs idempotency adapters in the Agents domain process while admission runs in the separate gateway process. It also revalidates activation against a projected configuration without fencing the aggregate version, so a concurrent setup change can invalidate the verdicts before execution.

**Approach:** Keep authorization, admission, and replay in the central EventStore gateway. Ship a small packable `Hexalith.Agents.EventStore` integration that a platform-owned gateway explicitly registers for Agents intent adapters and reserved-extension trust, then preserve the canonical receipt/result through the existing Agents API and UI. Activation carries the projected configuration version in the retained retry options. An exact-version projection gets live dependency revalidation; a newer same-Agent projection takes a dependency-free, fail-closed replay lane through EventStore; and the aggregate independently rejects every stale first execution.

**Decisions (2026-09-15):** Use explicit composition, not dynamic discovery: the platform gateway loads the Agents integration package, while the Agents domain host remains independently deployed. Use the existing allow-listed Dapr internal identity to accept the exact Agents reserved metadata keys only from the configured Agents app; public JWT callers, other Dapr callers, and missing policy registrations fail closed. An activation retry reuses its original ULID, payload, and expected configuration version; an already-admitted attempt replays, while a stale command with no matching admission conflicts and requires reload/new intent. Deliver the integration package and a split-provider topology test here, while the external Platform host change and EventStore package publication remain promotion prerequisites.

**Decision (2026-09-16, review iteration 8):** Dependency verdicts are trusted execution evidence, not semantic idempotency identity. Activation intent remains bound to target, payload, administrator authorization, and expected configuration version N, while provider/approver verdicts are excluded from its canonical intent. An exact identity/version-N projection is revalidated normally. An absent, not-created, foreign, or older projection reports `Unavailable` without dependency reads or dispatch. A newer same-Agent projection performs no dependency reads and submits the retained key/payload/N with canonical fail-closed dependency verdicts: EventStore replays an already-admitted equivalent outcome before routing, while a never-admitted command reaches the aggregate and is rejected by the N fence or dependency gates. Do not add a public lookup, retry store, fingerprint, or remote aggregate read.

**Decision (2026-09-14):** Deliver exact write/outcome/projection correlation as the current slice. Defer `ProvisionHexa` and legacy Party link/replace retirement together until Platform authority and `EXT-PARTIES-1` are concrete; do not retire the only current identity path before its replacement exists.

## Boundaries & Constraints

**Always:** Authorize before dispatch/read access; use canonical uppercase ULIDs and the EventStore receipt/result; bind idempotency to target, semantic payload, administrator authorization, and applicable concurrency metadata; keep transient dependency verdicts outside activation's canonical intent; keep adapters and reserved-extension authorization in the gateway service provider; accept colon-namespaced metadata only through an exact registered policy and the authenticated configured Dapr caller; read dependencies only from an exact identity/version-N activation projection; make the newer-projection replay lane fail closed without dependency reads; keep aggregates pure and reads behind `IReadModelStore`; preserve API/client/UI parity, the 250 ms / 8 s catch-up contract, tolerant `Unknown = 0` contracts, English/French whole strings, and lifecycle-versus-callability separation. Missing or ambiguous evidence is unverifiable.

**Never:** Register admission adapters only in `Hexalith.Agents.Server`; trust a header without Dapr authentication and allow-list validation; let public callers supply `actor:agentsAdmin`, dependency verdicts, or the internal activation-version extension (the public expected-version precondition is allowed and must be validated); compute activation dependency verdicts from an absent, foreign, older, or newer projection; dispatch an absent, not-created, foreign, or older projection; dynamically load plugins, call a remote canonicalizer, move admission out of EventStore, add an Agents retry store, or add an Agents-owned AppHost; collapse gateway and domain service into one DI container in the decisive test; confirm from a locally predicted version; mint a new key or change the activation precondition while an outcome is unresolved; change Party identity behavior; initialize nested submodules.

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|----------|---------------|----------------------------|----------------|
| Eventful write | Canonical receipt carries `Applied` and target version | Poll until the projection reaches that version | Missing/malformed payload is `UnableToVerify` |
| No-op | Receipt carries `AlreadyApplied` and unchanged version | Stop and render localized no-change outcome | Never poll for an unreachable version |
| Domain rejection | EventStore returns a typed rejection | Preserve prior setup and show the safe mapped failure | Never render Submitted or Success |
| Lost acknowledgement | UI retains one key and payload | Retry only that pair for idempotent replay | Block different submission until resolved/abandoned |
| Concurrent write | Another command advances projection | Confirm only against the original command-derived target | Local N+1 is forbidden |
| Trusted metadata | Agents BFF invokes gateway through allow-listed Dapr identity | Exact registered Agents keys reach admission and the aggregate | JWT callers, other callers, unknown colon keys, or absent policy are rejected |
| Activation fence | UI activates projected version N | Exact N revalidates dependencies; newer same-Agent state attempts admission replay with fail-closed verdicts; the aggregate executes activation only while state is N with valid gates | Absent/not-created/foreign/older reports `Unavailable`; never-admitted newer state is rejected; admitted newer state replays; retry retains N |
| Catch-up exhaustion | Target absent after 8 seconds | Keep attempt; show `awaiting projection` and refresh/retry | Never imply Success |

## Design Notes

`DomainResult.ResultPayload` already crosses EventStore only for completed success/no-op results and participates in idempotency replay. Carry only effect and resulting version; the gateway response owns message/correlation identity.

A later projected version confirms a command-derived target because ordered projection cannot skip that earlier event. No-op completes without polling; missing payload remains `UnableToVerify`.

Reserved-extension flow is deliberately small: the general sanitizer permits colon syntax, the controller continues
to discard caller-provided `actor:globalAdmin`, and every other colon key must be claimed by exactly one registered
policy. The Agents policy accepts only its exact key/value/command combinations when the authenticated
scheme is `DaprInternal` and `dapr_caller_app_id` equals the configured Agents app-id. Zero or multiple policy
claims reject before admission; a similarly named JWT claim is insufficient.

The activation version belongs to the retained public operation options as a caller-proposed concurrency
precondition, not as an authorization verdict. The Agents server validates it, strips any client attempt to populate
the internal extension, writes the positive invariant-decimal value itself, and EventStore includes it in canonical intent. A completed first attempt
can therefore replay with N even after its activation event projects N+1; a command not already admitted reaches
the aggregate and is rejected when current state differs from N.
